# Flaregrain · public build

Built 2026-11-14 from the team's rehearsal dashboard. Static files only: no account, no server, no model.

**NASA data.** NASA Physical Sciences Informatics (PSI) combustion repository, 24 investigations and their experimental tables (CC0-1.0 on 23 records; PSI-10's licence field is blank). NASA reports on NTRS as cited on each value. Context pages from nasa.gov, sma.nasa.gov and spinoff.nasa.gov are linked, not copied.

**What is generated (SI use).**
- Explanations under "Model explanation" were generated earlier by a local model (qwen3:4b via Ollama) for the demonstration pairs and filtered by the page's checker. They are marked "Generated earlier" and are not NASA statements.
- Trends are descriptive models fitted by Flaregrain to PSI table rows, labelled as such.
- Table summaries and data-issue readings are Flaregrain's wording; NASA's printed values stay visible.
- Code was written with Claude Code (Anthropic) and reviewed by the team. The full log is in the team's SI-use log.

**Third-party code.** GSAP 3.15.1 and d3-color / d3-interpolate (licences in Vendor/). Instrument Sans (OFL, in Vendor/).
