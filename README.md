# Flaregrain

An evidence dashboard for NASA's combustion experiments, built by Sparkline Foundry for the NASA Space Apps Challenge 2026 (Flame in Freefall, Halifax).

**Open it:** https://jpss2004-bot.github.io/flaregrain/

Flaregrain ranks NASA's 24 PSI combustion investigations for a fire-safety question, compares runs, and links every value to its NASA source. Where NASA's own sources disagree, or a table prints a value that can't be taken at face value, both readings stay visible.

This is a static copy: no account, no server, no live model. Model explanations shown here were generated earlier and filtered by the page's checker; they are marked as such. See [NOTICE.md](NOTICE.md) for data sources, licences and AI use.
